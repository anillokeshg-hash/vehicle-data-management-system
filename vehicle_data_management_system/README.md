# Vehicle Data Management System

A simple command-line application to manage vehicle records.
Built with Python 3 and SQLite (no extra packages required).

## Features
- Add, view, search, update and delete vehicles
- Statistics (total, average mileage, count by fuel type)
- Export records to CSV

## How to Run
1. Install Python 3.8 or higher
2. Open a terminal in this folder
3. Run:  python vehicle_management.py

A `vehicles.db` database file is created automatically on first run.

## Files
- vehicle_management.py : main program (database + menu)
